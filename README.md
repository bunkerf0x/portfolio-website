# Portfolio-website

Personlig portfolio för praktik inom webbdesign och webbutveckling. Byggd med HTML och CSS.

## Arbeta lokalt
Öppna mappen i VS Code. Använd Live Server eller kör `python3 -m http.server 8000` i mappen och öppna http://localhost:8000.

## Innehåll att komplettera
- Byt SVG-platshållarna i images/ mot riktiga projektbilder. De är egna illustrationer och kräver ingen extern bildlicens.
- Lägg till bekräftat namn, mejladress och eventuellt CV. Pup är det befintliga profilnamnet.
- Bekräfta exakta praktikdatum och år.
- Komplettera projekten med egna designval och processbilder.

Inga beroenden eller byggsteg behövs. Navigation och sidfot finns direkt i HTML för att fungera utan JavaScript. header.html och footer.html är referensfiler.
